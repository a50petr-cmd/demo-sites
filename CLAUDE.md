# demo-sites — демо-сайты для лидов Петра Алексеева

Здесь живут демо главных страниц для малого бизнеса (салоны, студии, цветы) Электростали и Ногинска.
Каждое демо — `<лид>/index.html`, публикуется на https://a50petr-cmd.github.io/demo-sites/<лид>/ (GitHub Pages, ветка main).
Таблица лидов: https://docs.google.com/spreadsheets/d/1bMOafRJk-Hs0nzUyNGoKe2F0WYb1YgFnSsvCgAWP_CQ

## Главное правило: каждый проект уникален
- Перед дизайном прочитай `docs/USED-STYLES.md`. Нельзя повторять шрифты, палитру и композицию первого экрана ни одного проекта оттуда.
- Направление выводится из самого бизнеса (его фото, логотип, интерьер, улица, ниша) и из 5–8 реальных референсов (`leads/<лид>/refs.md`).
- После утверждения дописать проект в `docs/USED-STYLES.md`.

## Правила демо
1. Факты только из `leads/<лид>/brief.md`. Нет данных — не выдумывать.
2. Фото — только из списка в brief (ссылки avatars.mds.yandex.net, размеры XXXL/orig). Людей с лицами не ставить.
3. Шрифты только с кириллицей (Google Fonts или Fontshare с кириллицей). Проверить, что кириллица реально рисуется.
4. Целая главная: первый экран, услуги с ценами, работы, отзыв, контакты, нижняя панель на телефоне.
5. `<meta name="robots" content="noindex">` и плашка «Демо-версия… Подготовил Пётр Алексеев».
6. Без Google Analytics. Один HTML-файл, CSS внутри.
7. Проверка: 390 px и 1440 px, нет горизонтальной прокрутки, заголовок не обрезан.

## Агенты (`.claude/agents/`)
- `ref-hunter` (sonnet) — референсы и 3 направления.
- `demo-designer` (sonnet) — сборка демо по выбранному направлению.
- `demo-reviewer` (haiku) — независимая проверка, только отчёт.
Opus не использовать. Одна задача — одна сессия. Результат — в файлы.
