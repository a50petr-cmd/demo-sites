| По любви (salon-po-lyubvi) | Oranienbaum + Manrope | светлый беж #f7f6f3, графит #1c1c1c, тёплый серый | журнальный, светлый, серифный заголовок | живой сайт |

Вывод из отказов: светлый беж + крупная антиква + графит = «По любви». Для следующих — другие семейства (гротеск, моно, рукописный, широкий), другие поля цвета, другая композиция.
