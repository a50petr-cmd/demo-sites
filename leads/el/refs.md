## Направление 1. «Шахматка»
- Идея: у «Эль» фирменный чёрно-белый шахматный пол и малиновый сертификат — сайт стоит на этом полу.
- Первый экран: белое поле, снизу на 45% высоты шахматный пол в перспективе (CSS), над ним гигантское «ЭЛЬ» малиновым капсом на всю ширину (вписать в 1440 без обрезки), справа фото длинного зала в арке-рамке, строка «Салон красоты · ул. Николаева, 9 · ежедневно 10–21», кнопки «Записаться» и «WhatsApp».
- Шрифты: Jost 700/800 капс (геометрический, как Futura, кириллица есть) + Commissioner 400/500 (кириллица есть).
- Палитра: чёрный #14111A, белый #FFFFFF, малина #D4126F, золото #C9A24A, румянец #FBE3EE.
- Живой элемент: плитки шахматки переворачиваются при наведении/скролле, пол «едет» вперёд при прокрутке; с prefers-reduced-motion статично.

## Направление 2. «Малиновый сертификат»
- Идея: страница как подарочный сертификат: малиновое поле, золотой завиток со стены прорисовывается линией.
- Первый экран: сплошное малиновое поле без карточек; по центру «Эль» контрастным дисплеем кремового цвета, вокруг SVG-завиток золотой линией; по бокам два фото 3:4 (сертификат с бантом, педикюрное кресло с завитком), повёрнутые на 3–4°; полоска контактов снизу.
- Шрифты: Yeseva One (контрастный дисплей, кириллица есть) + Geologica 400/500 (кириллица есть).
- Палитра: малина #B3105F, тёмная слива-чёрный #1D0A14, кремово-белый #FFF7F2, золото #D4AF5A, нежно-розовый #F6C6DA.
- Живой элемент: золотой завиток рисуется (stroke-dashoffset) при загрузке, банти секций повторяют его.

## Направление 3. «Для неё / для него»
- Идея: салон работает для женщин и мужчин (барбершоп, мужской ногтевой сервис): страница делится надвое.
- Первый экран: split 50/50, слева малина с белым заголовком «Для неё», справа чёрно-белая шахматка с «Для него», посередине круглая печать «Эль · 4,9 · 470 оценок»; под каждой половиной фото и 3 услуги с ценами.
- Шрифты: Wix Madefor Display 700/800 (геометрический гротеск, кириллица есть) + Arsenal 400/700 (кириллица есть).
- Палитра: малина #C2185B, чернильный #17121A, жемчуг #F2EEEA, хром #AEB8C0, золото #C8A24A.
- Живой элемент: переключатель «Для неё / Для него» меняет прайс и акцент страницы, половины раздвигаются по hover.

## ВЫБРАНО: 1
Шахматный пол — самое узнаваемое и уникальное, что есть у салона; он сразу отличает сайт от «По любви» (беж) и Гаврилиной (пастель), геометрический Jost отличается от заняты шрифтов. Реализуется чисто на CSS без риска обрезки заголовка.
Шрифты проверены по базе ui-ux-pro-max (subsets: Jost — cyrillic; Commissioner — cyrillic, cyrillic-ext); живой запрос к fonts.googleapis.com из среды недоступен, при сборке проверить рендер кириллицы.
